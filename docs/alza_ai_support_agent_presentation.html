Multimodal Ingestion & Loop Prevention

Security guardrails for attachments, infinite auto-reply mitigation, and idempotent processing.

Attachment Security

  • Extension Whitelist: Standard images, audio (.m4a, .mp3), and PDF manuals.
  • Magic Byte Validation: File signatures validated in-memory to prevent extension spoofing.
  • Path Sanitization: Prevents path traversal vulnerabilities.

Loop Mitigation

  • Self-Address Filter: Skips incoming emails where sender matches support box.
  • Prefix Matching: Ignores addresses starting with noreply, mailer-daemon.
  • RFC Header Rules: Checks Auto-Submitted and List-Unsubscribe headers.

State Deduplication

  • Negative Query Filter: Excludes emails tagged with alza-ai-processed.
  • Thread Locks: threading.Lock() serializes concurrent push webhook events.
  • Atomic Labeling: Label added only after successful draft creation / response dispatch.

    return any(email_msg.sender.startswith(prefix) for prefix in ["noreply", "postmaster"])

Hybrid RAG Knowledge System

Combining dense Gemini API embeddings with sparse BM25 search scored via NumPy dot products.

Score Fusion Algorithm

Retrieved technical chunks from PDF manuals, spare-part spreadsheets, and image descriptions are ranked using a hybrid scoring function:

Score = (0.6 × CosineSim) + (0.4 × BM25)

• Cosine Similarity: Computed locally via numpy.dot(embeddings, query_vector).

• BM25 Scoring: Evaluates exact keyword matches (Part numbers like PLS-FUS-101, error codes like ERR-401).
